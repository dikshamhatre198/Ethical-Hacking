EH PRACTICAL LIBRARY — QUICK PUBLISH GUIDE
==========================================

Files
-----
index.html              Main website
style.css               Styling
practicals.js           Practical content
app.js                  Search, navigation, copy buttons, theme toggle
assets/EH-practicals.pdf Original PDF from the conversation

PREVIEW LOCALLY
---------------
1. Extract the ZIP.
2. Open index.html in Chrome or Edge.
3. The original PDF is linked from the header. Search and Copy buttons work.
   (Clipboard access may depend on browser permissions; it normally works on localhost/HTTPS.)

PUBLISH ONLINE FOR FREE (GitHub Pages)
--------------------------------------
1. Sign in to GitHub and create a new repository, for example: eh-practical-library.
2. Upload all files and folders from this extracted folder. Make sure index.html is in the repository root.
3. Open the repository's Settings → Pages.
4. Under Build and deployment, select "Deploy from a branch".
5. Choose the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish. It will show the public website address in Settings → Pages.

ALTERNATIVE: NETLIFY DROP
-------------------------
1. Open Netlify and sign in.
2. Use its manual deploy / drag-and-drop option.
3. Drag the extracted eh-practical-library folder (or a ZIP of its contents, depending on the current interface).
4. Netlify will publish a site and provide a public URL.

NOTES
-----
- This is a static site: it does not require a server, database, or login.
- You must publish it to make it available online; this ZIP does not create a public URL automatically.
- Do not upload private credentials or real session cookies.
- Security testing must stay within your own device, an isolated lab, or a system you have permission to test.
- Practical 9 uses a safe prompt-only logging demo, not a system-wide keylogger.
- The PDF is included as assets/EH-practicals.pdf.
